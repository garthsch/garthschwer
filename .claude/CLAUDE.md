# PKM Migration (garthschwer.com)

Quartz 4 digital garden — migrating from Obsidian Publish/Sync to GitHub Pages.

## Tech Stack
- **Framework:** Quartz 4
- **Language:** TypeScript
- **Runtime:** Bun
- **Hosting:** GitHub Pages
- **Domain:** garthschwer.com
- **Repo:** github.com/garthsch/garthschwer

## Key Paths
- `content/` — Obsidian vault markdown files
- `quartz/` — Quartz framework source
- `quartz.config.ts` — Site configuration
- `quartz.layout.ts` — Layout configuration
- `public/` — Static assets

## Commands
- `bun install` — Install dependencies
- `bunx quartz build` — Build site
- `bunx quartz serve` — Local dev server
